# IILM University Landing Page

A responsive university landing page inspired by the visual identity of IILM University, built from scratch using **HTML5 and CSS3**.

## 🌐 Project Overview

This project is a frontend web development project created to practice and demonstrate fundamental web development skills, including semantic HTML, CSS layouts, responsive design, typography, spacing, and UI styling.

The page is designed as a modern university website with sections for academics, campus life, global opportunities, placements, admissions, and contact information.

## ✨ Features

* Responsive navigation bar
* IILM-inspired hero section
* Admissions announcement banner
* About IILM section
* Academic programs section
* Why IILM section
* Campus and student life section
* Global Connect section
* Career and placements section
* Call-to-action section
* Responsive footer
* Mobile-friendly layout
* Hover effects and transitions

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* CSS Flexbox
* CSS Grid
* CSS Media Queries
* Responsive Web Design

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/0x-aanya/iilm-landing-page-.git
```

2. Open the project folder:

```bash
cd iilm-landing-page-
```

3. Open `index.html` in a browser, or use the Live Server extension in VS Code.

## 🎯 Purpose

This project was created to strengthen my understanding of frontend development fundamentals and to build a complete landing page using HTML and CSS without relying on JavaScript or frontend frameworks.
